# Golos Text

Гарнитура интерфейса. Российский шрифт с полной кириллицей, автор — Илья Рудерман
и Юрий Остроменцкий (CSTM Fonts), опубликован в Google Fonts.

Файлы лежат в сборке намеренно: приложение обязано работать полностью офлайн,
поэтому шрифт не подгружается из сети во время работы.

Начертания: Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800 —
ровно те веса, которые задействует дизайн-система.

Лицензия: SIL Open Font License 1.1 — <https://openfontlicense.org>.
Источник: <https://fonts.google.com/specimen/Golos+Text>.
